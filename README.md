A deterministic one-line office joke for the One-Line Office Joke Laugh-Off: it writes a single original office joke (108 characters, one line, no trailing newline) to /output/entry.txt. The joke: the office plants are the only ones thriving here — they get watered, praised, and never asked to stay late. Fixed text, so the output is byte-identical on every run.

## Run it

```sh
python3 main.py
```
